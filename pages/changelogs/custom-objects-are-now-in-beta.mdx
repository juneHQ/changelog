This week we released Custom Objects in beta.

For this first version custom objects will be visible in the People List and support audience filters.

In the coming weeks we'll add support for custom objects in dashboards, reports, computed traits and CRM syncs.

Getting to this point took us a month and we hope to be able to release the final version in a month.


**Other improvements**

- Add border to bottom of the people list
- Show Created By in computed trait list
- Immediately compute traits after successfull creation or updates
- Fix an error causing object deletions for workspaces not to run
- Fix an error causing the people list to not be refetched when object type changes
